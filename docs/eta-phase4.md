# إضافة الخوارزميات 4 — تقدير وقت الوصول (ETA)

الأساس: `d098c42` (المراحل 1–3 مدمجة). لا migration ولا تغيير في routes أو DTOs.

## ما فُعّل
| الموضع | قبل | بعد |
|---|---|---|
| `EtaEstimator` (Entities/Pricing) | — | كلاس الحزمة كما هو (حتمي، UTC فقط، تقريب للأعلى، يرفض المدخلات السالبة والسرعة ≤ 0) |
| عرض السعر الفوري | الآن + التجهيز + `GetTravelMinutesAsync` | `EtaEstimator.ForQuote` بنفس الصيغة: الآن + التجهيز + هامش الاستلام + الرحلة |
| عرض السعر المجدول | `scheduledFor` | نفسه عبر `ForQuote` (موعد وصول)؛ التحقق من وجوده وصحته يبقى في `CheckOpeningAsync` → `InvalidScheduleTime` |
| عرض النافذة | `LateThresholdMinutes` | إعداد مستقل `Saham.Orders.EtaWindowMinutes` = 10 (قرار هندسي، لا قاعدة عميل) |
| `GetTravelMinutesAsync` | هامش + رحلة، والسرعة غير الصحيحة تُستبدل بـ1 صامتًا | هامش + `EtaEstimator.TravelMinutes` (الرحلة فقط)؛ السرعة غير الصحيحة تفشل |
| `Order.Accept` | الجاهزية + `TravelMinutes` | نفسه (الهامش مرة واحدة، لأن `TravelMinutes` المخزن = هامش + رحلة)، **و**الطلب المجدول لا يصل قبل موعده |
| `OrderTimeoutsWorker` | `EtaMaxAt <= now − grace` (متأخر عند المساواة) | `EtaMaxAt < now − grace` (BR-058: بعد الحد فقط) |

دلالتان لا تُخلطان: `Order.TravelMinutes` = هامش الاستلام + الرحلة؛ `EtaEstimator.Estimate.TravelMinutes` = الرحلة فقط.

الوقت: `AbpClockOptions.Kind = Utc` و`AbpDateTimeValueConverter` يقرأ أعمدة `timestamp without time zone` كـUTC، لذلك `Clock.Normalize` يكفي لتعليم قيمة Unspecified مخزنة أصلًا كـUTC. لا تحويل من وقت محلي.

## ما بقي اختياريًا (لم يُفعّل)
- `BeforePickup` / `AfterPickup`: يحتاجان تقدير وصول سائق موثوقًا ومسافة متبقية، ولا يوجد مصدر لهما سوى موقع خط مستقيم وتحديث دوري. إعادة حساب `EtaMaxAt` المحفوظ ستحرك مرجع التأخر (BR-058) باستمرار؛ تفعيلهما يحتاج حقل baseline منفصلًا (migration) وقرار عرض للزبون. مختبران وحدويًا فقط.
